# Kiomet AI 研究與控制平台

這是 Kiomet AI 的公開研究快照，包含可視觀察、證據與重播處理、PvP（玩家對玩家）決策流程、控制閘門、本機 Dashboard（儀表板）與隔離 Chromium（瀏覽器）觀戰。

目前的 PvP（玩家對玩家）流程仍在研究階段。單元測試與固定樣本通過，只證明對應案例符合契約；不代表已證明長時間、跨地圖或競技環境中的完整自主對戰能力。操作真實對局前，請先閱讀架構、測試與安全限制文件。

## 專案現況

程式包含從可見畫面與觀察證據建立狀態、整理對局重播、驗證 PvP（玩家對玩家）行動提案，以及經安全閘門派發行動的研究流程。Dashboard（儀表板）會顯示觀察結果與控制狀態；桌面瀏覽器仍在隔離的 Win32 Desktop Object（Windows 桌面物件）中執行。


公開版不包含瀏覽器設定檔、登入狀態、執行紀錄、截圖暫存、建置工具鏈、原始遊戲用戶端、原始反組譯傾印或本機「屎山」歸檔。經整理的戰鬥研究文件與小型研究工具保留於 `runtime/research/gpt_concurrent/`。公開可讀不表示第三方遊戲資料或程式碼可再散布；本倉庫未附授權檔。

## 一條命令啟動

在專案目錄的 PowerShell（命令介面）中：

```powershell
.\run.ps1
```

啟動後開啟 <http://127.0.0.1:8765>，可查看狀態、最近二十個決策、錯誤、記憶體與 Kiomet 首頁的 LIVE VIEW（即時觀戰）。

- 暫停：停止後續模擬行動及本機頁面鍵鼠測試；觀察器、世界狀態與觀戰畫面持續更新。
- 繼續：恢復已暫停的平台。
- 停止：封鎖後續行動，關閉專用瀏覽器；保留監控頁最終狀態。
- 停止後要重新運行：先在啟動的命令視窗按 `Ctrl+C` 結束監控服務，再執行啟動命令。這是命令介面正常中斷，不使用全域鍵盤鉤子。

命令列控制：

```powershell
.\control.ps1 pause
.\control.ps1 resume
.\control.ps1 stop
.\control.ps1 status
```

停止確認表示所有先前已送出的瀏覽器指令已完成或返回，之後不再派發輸入。按下停止前已送到瀏覽器的操作無法撤銷。

## 為什麼看不到彈出的瀏覽器視窗

有畫面的 Chromium（瀏覽器）位於獨立的 Win32 Desktop Object（Windows 桌面物件），並不是工作檢視裡的 Windows Virtual Desktop（Windows 虛擬桌面）。它與你正在操作的桌面分離，不會主動切換桌面。畫面可透過監控頁以每秒一張觀看；高頻模式為每秒四張，可手動關閉，也會在六十秒後自動降回低頻。

這不是一般的「最小化視窗」：普通啟動與最小化方案曾在此機器造成焦點切換，已淘汰。最終方案以 Windows（作業系統）原生程序建立介面明確指定隔離桌面，並檢查實際視窗歸屬。

使用自己的 Chrome（瀏覽器）、打字或移動滑鼠，不需要停用平台。不要手動切換到平台的隔離桌面；平台也沒有提供這項功能。

## 測試命令

只跑模擬閉環三十秒：

```powershell
.\run.ps1 -NoBrowser -Duration 30 -ExitAfterStop
```

完整三十分鐘運行後自動退出：

```powershell
.\run.ps1 -Duration 1800 -ExitAfterStop
```

單元與契約測試：

```powershell
.\tools\test.ps1
```

完整短測（會自行啟動與停止專用瀏覽器，請先關閉既有平台）：

```powershell
.\.venv\Scripts\python.exe .\tools\smoke_browser.py
```

## 安裝與重建

請提供 Python（程式語言）3.12 以上版本；安裝工具會在專案資料夾建立獨立環境，不安裝全域 Python（程式語言）。

```powershell
.\tools\setup.ps1 -Python '完整的 python.exe 路徑'
```

下載的套件、瀏覽器、暫存資料與快取都在專案內；不修改正常 Chrome（瀏覽器）的設定檔。相依套件版本固定於 `requirements.lock.txt`。

## 已知界線

- 瀏覽器鍵鼠隔離測試只操作專案自己的測試頁；它本身不證明 Kiomet 對局中的決策品質。
- 背景動畫、圖形與計時器的自動數值來自本機測試頁；Kiomet 首頁另以畫面預覽確認。
- 隔離桌面上的正常視窗背景執行已列入測試；最小化視窗、鎖定螢幕、睡眠與遠端桌面斷線不能由此推定通過。
- 程式不自動登入、不做隱匿、協議修改、封包注入或隱藏資料讀取。
- 紀錄採容量輪替；最新二十筆決策留在記憶體。瀏覽器自身的快取與設定檔仍可能隨使用增加；不自動刪除。
- 本機控制憑證僅用於避免網頁跨站操作；同一 Windows（作業系統）帳號的其他程式不屬於此憑證的隔離威脅模型。

## 即時觀戰

- 影像由 Playwright（瀏覽器自動化框架）的分頁畫面擷取取得，不使用系統桌面截圖。
- 平常每秒一張，高頻每秒四張；畫面旁會顯示實際擷取速度。
- 每次擷取只替換記憶體中的最新一張影像。多個監控頁分享同一份影像，不會各自觸發擷取。
- 暫停後，觀察與觀戰仍繼續。停止或錯誤後顯示最後畫面及畫面時間，避免把舊畫面當即時畫面。
- 只有發生執行錯誤或驗證失敗，才保存最新觀戰影像作為診斷。診斷最多十個固定槽位，另附原因及擷取時間。
- 監控頁另外清楚標記模擬行動與模擬分數；正式 Kiomet 分數及排名尚未接入。
- 詳細行為及桌面差異見 `docs/LIVE_VIEW.md`。
