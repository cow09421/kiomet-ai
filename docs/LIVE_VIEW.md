# LIVE VIEW（即時觀戰）

## 使用

啟動後在本機監控頁的即時觀戰區塊觀看。預設每秒一張，按「開啟高頻觀戰」提高至每秒四張；再次按下或經過六十秒會回到每秒一張。實際擷取速率與最後畫面時間會顯示在區塊中。

「暫停 AI」只封鎖行動與本機輸入測試。Observer（觀察器）、世界快照及遊戲分頁畫面擷取仍運行；規劃次數與行動次數不再增加。「繼續 AI」恢復規劃與行動。

目前遊戲畫面是正式 Kiomet 首頁，策略閉環仍為本機模擬。觀戰區的行動、驗證及意圖明確標示模擬；真實分數與排名顯示尚未取得。

## 畫面來源與隔離

畫面由 Playwright screenshot（Playwright 分頁畫面擷取）直接取得專用 Kiomet 分頁。沒有系統螢幕擷取、游標移動、鍵盤注入、前景切換或桌面切換。擷取與行動派發是分開的迴圈，因此暫停規劃不會中斷觀戰。

採用 Win32 Desktop Object（Windows 桌面物件）。這是原生視窗與輸入的隔離物件，**不是工作檢視中的 Windows Virtual Desktop（Windows 虛擬桌面）**。

## 關於「切換到 AI 桌面觀看」

已查閱作業系統文件。SwitchDesktop（切換桌面函式）會讓目標桌面可見並啟用它，使它接收使用者實體輸入，會改變你目前工作的輸入桌面。因此 v0.1 不提供桌面切換；即時觀戰已提供不改變目前工作桌面的觀看方式。

參考：[Microsoft（微軟）的桌面切換文件](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-switchdesktop)。

## 記憶體與硬碟上限

後端只保留最新一張 JPEG（影像格式）及最多二百四十個擷取時間點。網頁顯示下一張圖片後會釋放上一個影像物件。監控頁的網路請求序列執行，不堆積重疊的影像下載。

觀戰平常不寫任何截圖檔案。只有錯誤才會在 `runtime/screenshots/diagnostics` 寫入 `slot-00.jpg` 到 `slot-09.jpg`，並保存對應原因與時間。這十個固定槽位輪替覆寫，不會新增無上限的檔名。已有的早期驗收圖片會保留，不自動刪除。

若分頁暫時擷取失敗，會顯示錯誤並保留上一張畫面；連續三次失敗進入錯誤狀態，停止派發行動並關閉專用瀏覽器。

## 驗收

自動短測涵蓋：每秒一張、高頻每秒四張、圖片實際顯示、暫停時畫面與觀察持續、恢復行動、分頁動畫更新、使用者桌面沒有專用視窗、焦點違規為零。另有三十分鐘資源與截圖數量監測。

動畫量測是分頁額外的正常動畫回呼計數，不讀取內部遊戲狀態。正式遊戲實戰仍須另行驗收。
