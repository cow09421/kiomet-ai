## B. 隔離桌面啟動時 GPU 存取被拒（另一事件）

13:23:11、13:24:15、13:25:31 的三份傾印：`a76978d4-1962-4418-b79d-3085d87e4153.dmp`、`150cd243-8079-4282-884e-43f563ac5ed3.dmp`、`30859a27-589b-49ce-8630-6ee959d16846.dmp`。這些是瀏覽器主程序的 `0x80000003`，`chrome.dll+0xA67CB7F`，**不是前述渲染程序讀取違規**。啟動記錄 `runtime/logs/chromium-startup.log` 顯示 GPU 子程序反覆以 `0xC0000022`（存取被拒）退出，接著瀏覽器報 `GPU process isn't usable`。受限工具執行環境啟動會重現；以一般主機權限、仍使用原 Win32 Desktop Object（Windows 桌面物件）隔離架構啟動後恢復。當時程序啟動前後使用者桌面前景 PID 與游標均未變。這是獨立的**啟動權限問題**，不能拿來解釋前五次對局中渲染崩潰。
