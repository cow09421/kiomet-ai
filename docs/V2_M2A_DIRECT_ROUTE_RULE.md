The reusable certificate proves the path for its coherent before snapshot only when the direct goal has a
strictly smaller first-expansion f than every competing source neighbor. The
pinned mouse handler checks the popped goal before expanding it (0x58195..581ab).
Edge and heuristic distances use isqrt(distance_squared << 16); owner-self bias
is 512 and occupied/non-self bias is 8192. Scores for the entire visible neighbor
superset are compared; removing allied competitors cannot defeat the strict minimum.

Canonical neighbors are filtered to visible actors. Their presence alone is NOT
proof of a complete frontier. Require all eight valid adjacent grid cells to be
positively visible, decoded actors in the same snapshot. Static TowerId neighbors
can only occupy those cells, so the filtered list is then exhaustive. Missing
cells yield only an exclusion reason; hidden identifiers or payloads are not
exported. The frozen capture before state satisfies this stronger condition.

outside kinds6..8; func4260 0x14145d..141482 converts tag3 to None. Units::max_edge_distance
func1690 0xfbd0f..fbdbf considers nonzero counts. TowerType::ranged_distance func2183
0x10e590..10e5f9 examines generation plus each unit range. Exclude source types
with generation of kinds6..8, special/Ruler occupancy and empty mobile inventory.
This qualifies ordinary Barracks as well as Cliff; it does not assume all source
types follow the non-ranged branch. Positions remain facts from the pinned normal
integer-position offset table and are checked against their TowerId cells.

and an exact integer observation time equal to the snapshot sample time. Require

selection field cannot mean None. The pinned extractor and its offset table are
trusted prerequisites; checking a coordinate's TowerId cell does not authenticate
the offset table by itself.
