# 第六輪：正式版士氣靜態分析

證據限於 `runtime/research/source-map/production-client_bg.wasm`（SHA-256：`fae13d1d0a7683726db520ec5c687d67d701c874a5708aeb9bff6eaacf2f054c`）的離線反組譯，以及 `vendor/kiomet-ref` 公開參考碼。未連線、未執行正式版程式。下列位址為網頁組件（WASM）位元組位址；函式號以正式版索引為準。

## 結論與資料流

正式版**沒有獨立儲存的士氣數值**。`1778 Combatants::morale_advantage` 由交戰當下的兵力即時計算：`M(U)=min(3, floor(N(U)/2))`，其中 `N` 為非一次性兵種的單位總數。`1778:0x0ffb29..0x0ffb36` 呼叫 `4277 Unit::is_single_use` 後只加計非一次性兵；`0x0ffb43..0x0ffb51` 右移一位並鉗至 3。結果是非負的 32 位元整數，範圍 0～3，中性值 0。兵數變化會立即改變下一次計算值，沒有另設士氣更新或歸零寫入。

士氣能否進入戰鬥，由兩個**光環旗標**決定。正式版塔 `+45` 是一位有效值為 0／1 的位元組；部隊 `+21` 是從派出來源塔複製的位元組（`1791:0x1004a9..0x1004b0`）。塔 `+45` 在 `448:0x01a4e7..0x01a561` 依時間輪流更新：塔無主人，寫 0；有主人時讀玩家紀錄首 8 位元組中的可選國王位置，國王位置與本塔相同或相鄰，寫 1，否則寫 0。該位置由 `2071 World::player_inner` 尋址，`448:0x01a51a..0x01a55a` 讀取並比對。排程條件為 `(塔序號 XOR 節拍)&15 == 0`，各塔約每 16 節拍重算一次；旗標可能在國王移動／死亡後短暫保留舊值。部隊一旦派出持有複製值，不能以目前玩家國王位置重新推斷其 `+21`。

玩家紀錄首 8 位元組為可選塔座標的打包值：低 32 位的最低位用作存在判斷，高 32 位為 `TowerId`（塔識別碼，低 16 位 x、高 16 位 y）。`460:0x02df20..0x02df30` 以玩家索引乘 64 取得紀錄；`0x02dfb0..0x02dfb8` 將伺服器玩家輸入中的 8 位元組值複製到紀錄 `+0`；`0x02df6b..0x02df77` 在另一玩家輸入分支將 `+0` 寫 0。這證明客戶端的寫入／清除路徑；**伺服器如何決定／更新該位置及兩分支的正式名稱，公開資料不足，仍待確認**。因此不能說「國王死後即時歸零」或以玩家存活狀態取代國王位置。

## 戰鬥公式與方向

塔遭部隊攻擊時，`448:0x01acc6..0x01acd1` 先呼叫 `4969` 移除不能用於攻塔的部隊護盾，接著 `0x01acd4..0x01ad06` 設定**單一**有號 32 位元累積傷害初值：

```
A = Force[21] != 0
D = Tower[45] & 1 != 0
damage0 = A && !D ? +M(Force.units)
        : !A && D ? -M(Tower.units)
        : 0
```

初值範圍為 -3～+3；正值偏向攻方，負值偏向守方。兩邊都有旗標時互相抵銷為 0，不是各自加成後相減。`448:0x01ad06` 存入區域變數 6，之後的攻守輪流選兵、`2022` 傷害計算與殘兵寫回沿用該累積值。`2022` 最後參數是既有累積傷害，供核彈溢位保護使用，不是倍率。

部隊對向相遇時 `522:0x068fa4..0x068fd5` 有同構的初值分支（兩側皆用部隊 `+21`），`0x068fd6` 將其交給後續戰鬥。故士氣同時影響攻塔與路上部隊交戰。`2689 Force::progress_required:0x11ccf0..0x11cd15` 對 `+21==1` 另有約 4/5 的行進所需進度效果；這是同一旗標的**移動效果**，不屬於士氣函式本身。

公開參考碼 `common/src/combatants.rs:118-365` 從 `let mut damage = 0` 開始，不含 `morale_advantage`；`common/src/player.rs` 也沒有此可選國王位置。參考碼提供戰鬥骨架，但無法直接當作正式版勝負函式。

## 判定

儲存根：**強部分確認**（士氣衍生自兵力；光環源自伺服器同步的國王位置，伺服器產生規則未見）。型別、範圍、中性值、鉗制、戰鬥初值與接入：**靜態通過**。整體 `MORALE_STATIC_SEMANTICS = PASS`，限於已見正式客戶端靜態語意；伺服器端更新語意另標 `PARTIAL`。這個通過**不等於**完整戰鬥鏡像或實戰勝負驗證。
