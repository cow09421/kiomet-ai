# 保守攻擊規劃器契約 v0

首版攻擊候選限制在 SELF（己方）Many 普通移動兵 → ENEMY（敵方）直接相鄰塔。`evaluate_attack()`（攻擊評估）只驗證呼叫端指定的單一候選，不會搜尋地圖或自行選目標。

候選必須同時具備：

- 來源塔的完整可派普通兵力，並符合既有 `DeployForce`（部署部隊）語意。
- 直接相鄰、路徑合法、當前世界和目標擁有者資料新鮮。
- 已差分通過的普通戰鬥案例、明確攻守光環、無 Ruler（國王）／Shell／EMP／Nuke。
- 正式版曾接受同類敵方攻擊命令。
- `ROBUST_WIN`（穩健勝利）；`MARGINAL_WIN`（邊際勝利）不攻。

任何 `UNKNOWN`（未知）或 `UNSUPPORTED`（不支援）都會清除攻擊候選。攻擊評估本身不發行動；仲裁器只能從外部已提供、且全部條件通過的候選中決定是否回傳 `ATTACK_ENEMY`（攻擊敵人）。它不能補造兵力、路徑、戰果或勝率。

預設 `marginal_survivor_max=1` 是 `TUNABLE_POLICY`（可調政策），不是遊戲規則。若更改它，應重新檢查靜態案例及真實差分範圍。
